# §6.2 段2 第21バッチ報告 — 「バニッシュされない」の発生源オーナー限定

## 1. 結論

指定27効果をCSV原文で再実測した。26効果を採用、`WXK09-047-E1` は見送り。加えて指定外に完全同型の `WX13-029-E1` を1件発見して採用したため、採用総数は27効果である。

`sourceOwner` の省略は消費地点により fail-open/fail-closed が混在するため使わず、`sourceOwner:'any'` を明示した。効果解決では相手効果と自分効果の双方を防ぎ、バトル／パワー0のルール処理には広げていない。指定された原文限定4効果は `opponent` のまま契約固定した。

## 5. 退化していないことの実行証拠

上表27採用効果それぞれについて、liveから実際の `GRANT_PROTECTION` leafを抽出して独立E2Eを実行した（goldenのテスト名 `段2 第21バッチ E2E: <effectId>...`）。各効果で次の6点を個別assertしている。

1. `sourceOwner === 'any'`
2. `collectBanishEffectProtectedSigni(...,'opponent')` が対象を収集
3. `collectBanishEffectProtectedSigni(...,'self')` が対象を収集
4. `collectBanishEffectProtectedSigni(...,'rule')` は対象を収集しない
5. 相手効果の `BANISH` を実行して対象が場に残る
6. 自分効果の `BANISH` を実行して対象が場に残る

結果は27/27すべてPASS。従来の「相手効果を防ぐ」側を失っていない。期間付与キーワードも `PROTECTION:BANISH:any` を相手側・自分側の双方で読むようにした。

原文限定4件もgoldenで固定した。`WXDi-P03-074-E1`、`WXDi-P10-046-E1`、`WXDi-CP01-038-E1` は発生源種別/レベル制約つき収集で相手効果を防ぎ、`sourceOwner:'opponent'` を維持。`WXDi-P16-054` は実際の耐性leafが `E1b` に分離されているため、それを使い相手効果のみ防ぐことを固定した。
