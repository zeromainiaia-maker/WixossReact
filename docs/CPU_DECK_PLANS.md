## 何を書くものか（`src/screens/battle/cpuDeckPlan.ts`）

| 欄 | 効き方 | 点数（既定） |
|---|---|---|
| **キーカード** | エナに置かない・手札上限で捨てない・マリガンで戻さない・サーチで優先する | `keyKeep` **20000**（＝非常に重い。**入れすぎない**） |
| **優先して出す札** | 召喚の候補で加点 | `priorityDeploy` **4000** |
| **コンボ**（`first` → `then`） | `then` が手札にあれば `first` を先に出す／`first` が場に出るまで `then` を温存／`first` が場に出たら `then` を最優先 | `comboFirst` 5000／`comboThenReady` 8000／`comboThenHold` -8000／`comboKeep` 4000 |

🔴**いまの型は「出す」しか書けない**（`{ first, then }` はカード番号だけ）＝**【起】で使う・アーツで撃つ・スペルで使う**は表せない。
下の表で **⚠use** と付けたものが、**`S-14`（`{num, use}` の列）を入れないと書けないコンボ**＝**実在する**（2026-09-21 実測＝3デッキ）。

## この下書きから分かったこと（`S-14` の判断材料）

- **キーカードは21デッキ中20デッキで1枚に決まる**＝Lv4 ルリグの【常】が参照する札（`WD01`〜`WD05` は全部この形）かデッキの主役。
- **コンボは17デッキ中13デッキで書ける**が、**そのうち3つ（`WD06`／`WD08`／`WD16`）は「【起】で使う」を書けないと成立しない**
  ⇒ 🔴**`S-14`（`{num, use}` の列）が要るコンボは実在する**（下書きを作る前は corpus に0件だった）。
- **「N体並べる」条件（`SP06`／`SP07`／`天使軸1`）は2枚のコンボでは表せない**＝`S-14` を実装しても書けない。
  ⇒ 必要なら別の型（「この種族をN体並べる」）になる＝**いまは `priorityCards` で代用する。**
