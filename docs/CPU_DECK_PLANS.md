## 何を書くものか（`src/screens/battle/cpuDeckPlan.ts`）

| 欄 | 効き方 | 点数（既定） |
|---|---|---|
| **キーカード** | エナに置かない・手札上限で捨てない・マリガンで戻さない・サーチで優先する | `keyKeep` **20000**（＝非常に重い。**入れすぎない**） |
| **優先して出す札** | 召喚の候補で加点 | `priorityDeploy` **4000** |
| **コンボ**（手の列） | 後の手の札が手元にあれば前の手を先に打つ／前の手が済むまで後の手は温存／前が済んだら後を最優先 | `comboFirst` 5000／`comboThenReady` 8000／`comboThenHold` -8000／`comboKeep` 4000 |
| 🆕**効果の対象**（§5.7 `S-32`） | **大まかな指示**＝パワー・効果が強いもの（既定）／**パワーを下げて落とせるものを優先**／弱いもの | — |
| 🆕**狙う・避ける** | **固有のカード指定**＝効果の対象に選ぶ／選ばない | `targetPrefer` 12000／`targetAvoid` -12000 |
| 🆕**狙う条件・避ける条件** | **属性での指定**＝クラス（41種）／レベル◯以上・以下／パワー◯以上・以下 | 同上（重ねると2回ぶん乗る） |
| 🆕**狙い方の切替** | **この札の効果のとき**／**盤面の条件のとき**（自分か相手のライフ2枚以下・相手の場3体）に狙い方を上書き。**上から順に最初に当たった1つ** | — |

🆕**「パワーを下げて落とせるものを優先」が効くデッキ**（相手を対象にパワーを下げる／0にする効果を持つ・2026-09-21 実測）＝
**`WD11`（6件）／`WD07`（5件）／`WD08`（4件）／`WD05`（3件）／`WD14`（3件）**。
⚠**それ以外のデッキでは並びが変わらない**（バニッシュ等は「全部落とせる」ので既定と同じ）。
⚠**「狙う・避ける」に出るのはそのデッキの札だけ**（名指しは自分の札に限る）。
🆕**相手の札は「狙う条件／避ける条件」で指定する**（クラス・レベル・パワー帯）＝クラスの一覧は**全カード**から作ってある。
🔑**使い分け**＝「相手のパワーの大きいもの」＝既定の狙い方／「パワー1万以上を狙う」＝狙う条件／
「レベル1以下は避ける」＝避ける条件（小物に除去を撃たない）。

🆕✅**2026-09-21＝`S-14` を実装した**＝コンボは**順番に打つ手の列**で、1手ごとに **出す／【起】で使う／アーツで撃つ／スペルで使う** を選べる

## この下書きから分かったこと（`S-14` の判断材料）

- **キーカードは21デッキ中20デッキで1枚に決まる**＝Lv4 ルリグの【常】が参照する札（`WD01`〜`WD05` は全部この形）かデッキの主役。
- **コンボは21デッキ中13デッキで書ける**（14件）。**そのうち3つ（`WD06`／`WD08`／`WD16`）は「【起】で使う」が要る**
  ⇒ 🔴**`S-14` の母集団は「下書きを作って初めて」出てきた**（作る前は corpus に0件だった）。
  ✅**`WD06`／`WD08` は実装後に動作確認済み**（自己対戦で該当の【起】を毎戦使う）。⚠**`WD16` はコストの都合で未達**（上記）。
- 🏁**「N体並べる」条件は書く必要が無かった**（2026-09-21・`S-31` ① を測って否定）＝
  **盤面の採点が「並べた後の実効パワー」を見ている**ので、`＜原子＞3体で全体＋2000` のような見返りは
  **作戦データ無しで CPU の判断に出る**（golden `§5.7 S-31 ①` が固定）。
  📏実測＝自分の場の並びを条件にする効果 **147**／うち **109（74%）はパワーに出る**。
  ⚠残り38（`GRANT_KEYWORD` 10 ほか）は**パワーに出ない**が、強さ表が `activeCondition` を見ずに
  **満額で数えている＝過大評価**（取りこぼしではない）。
